# Avito → Telegram: последнее объявление

Бот на Python, который открывает настроенную страницу поиска Avito, выбирает **первое объявление из результатов**, затем один раз открывает его карточку и отправляет в Telegram расширенную информацию: заголовок, цену, место, время публикации, описание, продавца, фото и ссылку.

Есть два режима:

- `/latest` — получить последнее объявление вручную прямо сейчас;
- `/watch` — включить автоматическую проверку. Если ID первого объявления изменился, бот отправит его в чат один раз.

## Как определяется «последнее»

Бот не может достоверно определить дату объявления, если сама страница Avito не сортирует результаты по дате. Поэтому откройте поиск в браузере, выберите сортировку «сначала новые» / аналогичную, скопируйте URL и положите его в `AVITO_SEARCH_URL`. Бот берёт только первую карточку страницы и не сканирует остальные страницы.

Если Avito не отдаёт серверный HTML или меняет вёрстку, парсер может потребовать обновления. В таком случае используйте разрешённый официальный способ интеграции, если он доступен для вашего аккаунта.

## Запуск

1. Создайте бота через `@BotFather` и получите токен.
2. Скопируйте настройки:

   ```bash
   cp .env.example .env
   ```

3. Заполните `.env`:

   ```dotenv
   TELEGRAM_BOT_TOKEN=123456:replace_me
   AVITO_SEARCH_URL=https://www.avito.ru/moskva?q=велосипед
   AVITO_USER_AGENT=MyAvitoLatestBot/1.0 (+mailto:you@example.com)
   ```

4. Установите зависимости и запустите:

   ```bash
   python3.11 -m venv .venv
   . .venv/bin/activate
   pip install -e .
   python -m app
   ```

5. Откройте чат с ботом и отправьте `/start`, затем `/latest`.

База `data/bot.sqlite3` запоминает ID уже отправленного объявления и состояние HTTP-кэша, поэтому после перезапуска бот не отправит его повторно. При первом запуске `/watch` только запоминает текущий результат как базовый — старое объявление не считается новым.

## Команды

- `/start` — включить автоматические уведомления;
- `/latest` — запросить и прислать первое объявление сейчас;
- `/watch` — то же, что `/start`;
- `/stop` — выключить автоматические уведомления;
- `/status` — показать состояние и время до следующего запроса;
- `/check` — алиас команды `/latest`.

Ручная и автоматическая проверка используют общий cooldown. Минимальный интервал — 60 секунд, по умолчанию 300 секунд (5 минут). При автоматической проверке страница карточки открывается только когда ID первого объявления действительно изменился; повторные проверки не делают второй запрос за деталями. Это не позволяет случайно превратить команду `/latest` в частый сканер.

## Ограничение доступа

Для личного бота задайте свой числовой Telegram chat ID:

```dotenv
TELEGRAM_ALLOWED_CHAT_IDS=123456789
```

Несколько чатов указываются через запятую. Если список пустой, любой пользователь, нашедший username бота, сможет отправить `/start`. Токен бота никому не передавайте.

## Docker

```bash
cp .env.example .env
# заполните .env

docker compose up -d --build
docker compose logs -f
```

Каталог `./data` монтируется в контейнер и сохраняет базу при обновлении.

## Безопасный режим работы с Avito

В проект намеренно не добавлены:

- ротация IP и прокси для обхода ограничений;
- подмена отпечатка браузера;
- обход CAPTCHA;
- повторные запросы при `403` или `429`.

При `403`, `429` или обнаружении страницы CAPTCHA бот ставит мониторинг на паузу с exponential backoff. Это снижает нагрузку, но не является гарантией от блокировки. Соблюдайте правила Avito и мониторьте только источник, который разрешено использовать. Для production-сценария проверьте официальные возможности на [портале разработчиков Avito](https://developers.avito.ru/).

## Структура

- `app/source.py` — HTTPS-запрос к странице поиска, парсер первой карточки и один дополнительный запрос к карточке для расширенных данных;
- `app/monitor.py` — cooldown, запоминание ID и backoff;
- `app/database.py` — SQLite для состояния и подписчиков;
- `app/bot.py` — Telegram-команды и сообщения;
- `app/config.py` — конфигурация и проверка URL.
